arTerm - Third-party notices
==========================

Scope: arTerm 0.6.1 Windows x86_64 and ARM64 MSVC binary distributions.
Inventory: union of 62 third-party crate/version entries reachable through
normal (non-dev, non-build) dependency edges in Cargo.lock, resolved with:
  cargo metadata --locked --filter-platform x86_64-pc-windows-msvc
  cargo metadata --locked --filter-platform aarch64-pc-windows-msvc

are target-specific alternatives included together in this shared notice.
This includes production derive/procedural-macro dependencies conservatively;
it is a dependency inventory, not a claim that every crate contributes linked
machine code. Build-only autocfg and version_check, test-only dependencies, and
other-platform-only dependencies are excluded. Installer features add no
separate dependencies. Refresh this file when the locked dependency graph changes.
